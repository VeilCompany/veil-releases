## Как начать

1. Скачайте `veil-app.exe` из [последнего выпуска](../../releases/latest). Установка не нужна — это один файл.
2. Запустите его. Windows один раз спросит разрешение на запуск от имени администратора (нужно, чтобы друг, которому вы разрешили управлять компьютером, мог работать с любыми окнами; можно отказаться).
3. Программа сама проверит связь и покажет ваш ID. Обменяйтесь с другом файлами контакта `.veil` (кнопка «Поделиться») — и звоните.

## Что умеет

- 📞 Звонки с хорошим звуком, пинг и качество связи на экране
- 💬 Переписка — только текст и ссылки, ничего не хранится
- 🖥 Показ экрана или окна, со звуком
- 🖱 Управление компьютером друга — только после его «Разрешить», забрать можно в любой момент
- ⏰ «Разбудить» — будильник, голос и трясущийся экран у друга
- 🔔 Трей, автозапуск, звуки, уведомления — как в старой доброй ICQ
- 🔄 Обновления: программа сама замечает новую версию, кнопка «Обновиться» ставит её

## Безопасность

- Аккаунтов нет: ваш ID — это ваш ключ шифрования. Ни телефона, ни почты.
- Сообщения подписаны и зашифрованы для получателя; звонок идёт напрямую, со своими одноразовыми ключами.
- Каждая сборка здесь **подписана ключом выпуска**. Программа проверяет подпись и не поставит обновление, которое подписано не им, даже если его выложить сюда.

Проверить файл вручную: в каждом выпуске лежит `latest.json` с размером и SHA-256 файла.

```powershell
Get-FileHash .\veil-app.exe -Algorithm SHA256
```
